# Wolfx 個人閲覧用接続

今回は公開しません。Wolfxの予報WebSocketを標準で有効にしています。個別の再提供許可を取得したという意味ではありません。既存Workerや認証・Windows常駐収集処理は変更していません。

2026年10月30日改定の[利用規約](https://wolfx.jp/legal/terms/)では、通常のエンドユーザー向けアプリによる閲覧・内部処理と、別のアプリへデータを供給する独立した再提供が区別されています。後者は明示的許可が必要です。今回の構成を独立した配信APIとして他者へ提供する変更はしていません。上流データの条件も引き続き適用されます。

[WebSocket仕様](https://wolfx.jp/docs/websocket/)に従い、ブラウザー内でEEW接続を1本にまとめ、心拍を監視し、切断時は待ち時間を置いて再接続します。HTTP復旧取得は60秒キャッシュ。非公式配信であること・出典を表示します。

個人用モードを止める場合、起動するPowerShellで次を設定してから従来の起動方法を使用します。

```powershell
$env:EV_WOLFX_MODE = 'off'
```

個人用へ戻す場合は `private` を指定します。既存の `EV_WOLFX_AUTHORIZED=1` は優先されるため、接続停止時はその環境変数も解除してください。APIキーやパスワードは不要です。全国の観測点別の秒単位実測震度が追加されたことを意味しません。

取得可能な予報の報数、震源、規模、深さ、予想震度、対象地域、取消・最終、更新理由などを既存のライブ画面に統合します。提供されない項目は作りません。接続確認と未確認事項はTEST_RESULTS_0_51.mdを参照してください。
